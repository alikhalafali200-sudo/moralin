# Moralin MVP\n\nArabic RTL Link-in-bio SaaS starter (Next.js + Supabase).\n\n## Setup\n1. Install Node.js 20+.\n2. `npm install`\n3. Create a Supabase project and run `supabase/schema.sql` in SQL Editor.\n4. Copy `.env.example` to `.env.local` and fill the Supabase URL and anon key.\n5. `npm run dev`\n\n## Current scaffold\n- Landing page\n- Supabase email auth UI\n- Profile editor (display name, slug, bio, links)\n- SQL schema with profile RLS policies\n\n## Important next steps before production\n- Add slug validation and reserved names.\n- Build dynamic public profile route and click tracking.\n- Add image upload storage policies.\n- Implement admin role, moderation, analytics, rate limiting, and custom themes.\n- Validate URLs and escape user-generated content.\n\nThis starter is not production-secure until the above tasks and auth/session checks are reviewed.\n
